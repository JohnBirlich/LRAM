# 0.14.2 validation: universal warm-up and recovery

The user confirmed Auto-rejoin is enabled and requested the same startup grace for **all** profiles. This supersedes the strict no-grace behavior in 0.14.0/0.14.1. Exact user error code/log has not yet been supplied; do not claim it has been reproduced.

## Policy

CPU rate ceiling and Eco are released while loading/disconnected/teleporting/verifying, followed by fixed 90 seconds from verified in-game entry. Every global/per-client/manual CPU profile uses this final override, after strict/manual/fair/memory-cap calculations. Affinity and trim are separate; FPS/graphics are applied at launch and never switched automatically at the end of grace. No spontaneous restart, forced resolution or window-size change.

Legacy warmupS cannot shorten the fixed 90 seconds. Apply during grace updates requested settings without reintroducing CPU/Eco limits. Applying after grace changes eligible live settings without restarting. Loading does not expire into a cap. New game generations and lost process confirmation reset readiness. Existing Windows jobs from older LRAM instances may retain caps that cannot be removed through a new handle; restart affected Roblox clients explicitly after upgrading if old caps persist.
