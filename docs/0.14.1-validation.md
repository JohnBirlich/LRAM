# 0.14.1 hardware inventory correction

## Scope

0.14.0 still showed three NVIDIA rows on the user's PC while Device Manager showed one NVIDIA, MuMuPlayer Virtual Display Adapter and StarDesk Virtual Display Adapter. GDI also returned Generic PnP Monitor while Windows had MSI model names. Deduplicating DXGI LUIDs alone was insufficient. The exact driver mechanism is not established from screenshots.

0.14.1 enumerates present PnP display-class devices for inventory. Device instance IDs deduplicate records, not names. PCI devices are listed as graphics adapters, ROOT/SWD devices as virtual/software display adapters, other buses separately. DXGI supplies VRAM only on an exact adapter device-path/PnP instance match, or a driver-key AdapterLuid match. Conflicting device-path memory reports remain Unknown. Unknown is intentional when that read/match is unavailable; no name/vendor/position guesses.

Active displays use QueryDisplayConfig. Target device interface paths map to PnP monitor instances for fallback names; source ID and adapter LUID map source resolution. Target rational refresh preserves fractional Hz. Topology changes retry bounded buffer queries. Device IDs/paths never enter the serialized DTO or logs. All inventory reads are read-only.

Home client menu exposes one **Profile** action for the combined panel; duplicate **Limits** was removed.

## Automated gates

- Frontend production build, privacy projection tests, capacity tests.
- Windows Rust tests and Clippy with warnings denied.
- Native fixtures: one PCI GPU plus two ROOT/SWD drivers despite three DXGI aliases; repeated PnP device excluded; two equal-model PCI devices retained; unmatched VRAM unknown; unknown buses not misclassified as PCI/virtual; monitor interface-path conversion; fractional/invalid refresh values.
- UI mock checks: virtual/software section and privacy masking. Mock inventory is explicitly labeled demo, not the sandbox/user's hardware.

## Manual Windows acceptance (not certified by CI)

1. Compare with Device Manager: on the reported PC, expect the physical NVIDIA separately from MuMuPlayer and StarDesk, using actual Windows names. Never force one card globally. Check two physical identical-model GPUs if available.
2. Check VRAM against Windows only if a reliable LUID match exists; missing values must say Unknown, never repeat another device's VRAM.
3. Verify G2712 / MAG 275QF / MP271 names where Windows exposes them. Move/reorder displays, unplug/reconnect, enable clone/extend and change refresh. Each name must stay bound to its own active path, not row index. Virtual/remote active screens may also appear.
4. Check 59.94 Hz and mixed-refresh displays. Unavailable names/modes must remain Unknown; a generic name supplied by Windows may still be generic.
5. Toggle Privacy and restart LRAM: physical, virtual, other and display facts must be hidden. Confirm actual identities are restored only on turning Privacy off.
6. Regression-check strict CPU, profiles/confirmed restart, process identity/recovery; these behaviors are not intentionally changed.

Publish only after exact-source Windows CI and release build succeed; verify source tag and installer/SHA256SUMS. Preserve 0.14.0 and all earlier assets. No signing or antivirus clearance is claimed.
