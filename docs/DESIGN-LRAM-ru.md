# Дизайн LRAM

Итоговое оформление интерфейса: одно направление, собранное по двум референсам
(`image-1.png` и `Снимок экрана 2026-11-01 164554.png`). Прежние три варианта
(slate / studio / grid) удалены — они были нужны только для выбора.

## Что это за направление

Тёмный «инструментальный» интерфейс: плотный, прямоугольный, с тонкими рамками и таблицей
по центру. Никаких скруглений, свечений и градиентов — только слои поверхностей, 1 px линии
и цвет как сигнал (зелёный / красный / янтарный), а не украшение.

Палитра снята с референса:

| Роль | Цвет |
|---|---|
| Фон окна (`--frame`) | `#0c1017` |
| Рабочая поверхность (`--bg`) | `#111720` |
| Панель, шапка, сайдбар (`--panel`) | `#171e2a` |
| Поля ввода, лог | `#0f131b` |
| Линии, рамки (`--line`) | `#2a3446` |
| Нажатое / сегмент (`--hover`) | `#232e3f` |
| Акцент, кнопка (`--accent`) | `#437beb` (hover `#5b91f5`, кант `#2f62cc`) |
| Заголовки, микро-подписи | `#70a4ff` / `#93bdff` |
| Основной текст | `#f0f2f6` |
| Второстепенный текст | `#b1bccf` |
| ОК / ошибка / внимание | `#9ad5b0` / `#ff8074` / `#ffc670` |

## Из чего собран экран

1. **Полоса заголовка, 58 px.** Слева логотип, `LRAM`, чип `v0.10.0` и подпись
   `Local Roblox Account Manager`; справа — служебные кнопки (обновить, тема, замок,
   окно). Место между ними перетаскивает окно.
2. **Сайдбар.** Прямоугольная панель с 1 px рамкой, над списком разделов — микро-заголовок
   капсом (`РАЗДЕЛЫ`), пункты без заливки: активный помечен рамкой и синим текстом.
3. **Рабочая область.** `--bg` внутри рамки, отступ 6 px от сайдбара и краёв.
4. **Полоса счётчиков.** Шесть ячеек в общем контуре, значение окрашено: всего, в игре,
   онлайн (зелёный), оффлайн, вышел из аккаунта (красный), не проверен (янтарный).
   Каждая ячейка — фильтр таблицы.
5. **Таблица.** Шапка капсом, разделители между колонками, строки 46 px (38 px в плотном
   режиме), хайрлайн между строками, выделение — синяя подсветка без заливки.
6. **Нижняя панель журнала.** Свёрнутая полоса на всю ширину: заголовок капсом, счётчик
   строк и последняя строка; разворачивается в лог-колодец с моно-строками
   (warn — янтарный, error — красный), кнопками «Копировать», «Очистить» и «Папка логов».

## Как это сделано в коде

- `src/styles/directions.css` — весь слой оформления под `:root[data-direction="lram"]`:
  токены, формы кнопок/полей/чипов/сегментов, таблицы, диалоги, меню, тосты, полоса
  счётчиков, лог-панель. Без атрибута `data-direction` (или со значением `soft`) файл
  ничего не меняет — остаётся исходный вид, это удобно для A/B при правках.
- `src/theme.css` — структурные классы, которые работают в любом направлении
  (`.brand`, `.nav-heading`, `.counters`, `.counter`, `.logdock`), чтобы разметка не
  зависела от темы.
- `src/ui/TitleBar.tsx` — экспортирует `PRODUCT`/`TAGLINE` и рисует блок бренда.
- Знак: `src-tauri/icons/app-icon.svg` и `scripts/make-icons.py` (из них — png и icon.ico),
  `Logo` в `src/ui/Icon.tsx`, плитка в сплэше.
- `src/ui/LogDock.tsx` — нижняя панель журнала (живые строки `log://log` + хвост `lram.log`).
- `src/ui/DirectionSwitcher.tsx` — dev-переключатель `LRAM ↔ Soft Deck`; собирается только
  в dev-режиме и в прод не попадает.

## Проверено

`npx tsc --noEmit` — без ошибок; `npx vite build` — собирается; `node scripts/check-i18n.mjs` —
все ключи, которые просит код, есть в `en.json`. Rust в этой среде не собирается (Windows-only крейты), поэтому изменения
`src-tauri` проверены чтением кода, а не компиляцией.
